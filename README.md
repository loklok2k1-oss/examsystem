# 考試系統 — 獨立版

**版本 1.2.0（2026-11-21）**｜更新紀錄見 `CHANGELOG.md`，版本號見 `VERSION`。

呢個係可以下載、自己保存、上傳去自己伺服器嘅獨立版考試系統，VTS 同 430 備考用。唔係 Muse 入面先用得嘅版本，有前後端加資料庫。

## 入面有乜

- 帳號：首次開啟先建立管理員帳號，之後考生自行註冊；密碼用 PBKDF2 雜湊，唔存明文；分考生同管理員角色；帳號管理可以升降級；登入狀態存資料庫，伺服器重啟唔會登出晒所有人。
- 題庫管理（管理員）：單題新增、修改、刪除連選項編輯器、預覽連解析；按考試、難度、題型、關鍵字篩選；CSV 批次匯入，欄位缺漏逐行報邊行錯，重複編號可以揀跳過或者覆蓋；CSV 範本用 `exam` 欄位，含 4 行示例，匯入前要刪走示例行；另有睇範本內容加一鍵複製，同直接貼上 CSV 內容匯入；答案格式有驗證，唔會存入永遠答唔啱嘅題。批量管理：每題可以勾選，全選今頁 / 全選篩選結果 / 取消全選，批量刪除（連答題紀錄、收藏、相關留言一併清除）、批量改分類（VTS / 430）、批量改難度。
- 題目媒體（圖片／影片）：題目可以加圖片同影片，最多 5 個。圖片放題幹或者答案選項（例如選項 B 係一幅圖），影片主要放解析（例如一條短片講點解答案係咁），解析都可以加圖片；媒體跟住題目喺刷題、模擬考、錯題本、預覽、成績報告顯示，唔會影響計分。詳情見下面「題目媒體」一節。
- 匯出備份（管理員）：儀表板「備份與匯出」可以匯出題目 CSV（格式同匯入範本一樣）、匯出學生帳號 CSV（唔含密碼雜湊）、下載成站備份 JSON、還原備份 JSON（合併方式，失敗成個取消）；題庫管理頁可以匯出目前篩選嘅題目 CSV；帳號管理頁可以匯出學生帳號 CSV。
- 安全：密碼 PBKDF2 雜湊（新註冊同改密碼最少 6 個字）、登入失敗 5 次鎖 15 分鐘、登入狀態 30 日過期、基本安全 headers、管理員接口全部要管理員身份、考生唔可以直接由題目列表拎到答案。
- 刷題模式：按考試、難度、題型隨機抽題，一題一頁，交答案即顯示對錯同解析，解析預設收起，可以收藏；簡答出參考答案自評。
- 模擬考：隨機組卷或者手動選題，計時器、題號導覽、標記待檢查、暫停離開後再登入可恢復，恢復時直接跳去第一條未答嘅題；交卷自動閱卷，多選順序唔敏感；成績報告逐題連解析；考卷列表可以刪除考卷；考試頁底部有固定狀態列，顯示計時、已答、未答、待檢查數同自動暫存時間；未交卷草稿唔會漏入錯題本。
- 錯題本：自動收集，按考試、來源批次篩選（自由刷題或者邊份模擬考卷），每題顯示來源，錯題重做模式。
- 留言：全域留言板加每題討論，管理員或者本人可以刪除。
- 儀表板：個人（答題總數、正確率、各考試正確率、模擬考分數趨勢）同管理員（題庫總數、題型分佈、難度分佈、各考試題目分佈，X 軸用整數刻度；另有學生表現分析，見下面一節）。
- 學生表現分析（管理員）：儀表板「題庫總覽」下面嗰張卡，睇全站弱項、必錯題目榜、逐個學生表現，撳帳號名睇學生詳情。
- 其他：深色模式可切換；手機頂部導覽自動換行；彈窗可以用 Esc 關閉；登入狀態同主題用安全儲存，瀏覽器封鎖儲存都唔會全頁白屏；載入出錯會顯示原因同恢復掣。

## 之前更新（v1.1.0，2026-11-17）

今次係一次缺點修復，唔係加新功能。修咗嘅嘢：

1. **備份漏咗組卷模板（最嚴重，會唔見嘢）**：之前成站備份 JSON 冇包 `paper_templates`，還原之後模板會全部唔見。而家備份（v2）包埋模板，還原亦會還原埋；舊版 v1 備份照樣還原到，淨係冇模板嗰部分。
2. **改題會影響已經開咗嘅卷**：之前成績報告同交卷計分都係即時讀題庫，管理員喺學生做緊卷嗰陣改題或者刪題，會改埋份卷嘅內容同分數。而家開卷嗰陣會將成份卷嘅題目全文存做快照，之後點改題庫都唔影響舊卷；舊卷冇快照，照舊即時讀題庫。
3. **交卷唔係交易、重交會重複計分**：之前交卷係逐條寫答題紀錄，中途出錯或者重複撳交卷，可以寫多咗紀錄。而家成個交卷包喺一個交易入面，出錯成個取消；重交之前會先清走呢份卷舊紀錄，唔會重複計。刷題重複撳交答案亦唔會再重複記分。
4. **暫停離開照計時間**：之前「暫停離開」之後再返嚟，用時係由開卷嗰刻計到交卷，瞓醒再做都照計。而家繼續作答嗰陣會扣返暫停咗嘅時間（差距細過 5 秒當連續作答）。
5. **Railway 部署 crash（2026-11-16）**：加咗 `GET /health` 健康檢查端點（Railway 會用佢判斷程式係咪活緊）、`railway.json`（健康檢查 + 失敗自動重啟）、`.nvmrc` 鎖定 Node 24（舊版要求 Node 22+，但平台預設可能裝舊版 Node，程式一啟動就死，係最可能嘅 crash 原因）。另外加咗優雅關機（收到 SIGTERM 先停收請求、寫返 WAL 再退出）、port 衝突提示、未處理錯誤會記低先退出等平台重啟。資料庫改用 WAL 模式加 5 秒等待，多人同時交卷唔會咁易話鎖死。**不過要講明：crash 嘅真正原因未核實到**，因為睇唔到 Railway 嗰邊嘅 log；呢啲係針對最可能原因嘅修復，重新部署之後要去 Railway 睇下係咪真係起返。
6. **更新完手機仲見到舊版**：之前 `app.js` 冇版本號，手機瀏覽器會快取舊檔案，搞到 11 月 16 號嗰次以為新功能唔見咗。而家 `index.html` 引用 `app.js?v=1.1.0`，伺服器亦會話瀏覽器 html 同 js 唔好快取。更新之後第一次開可能仲要完全閂咗個頁面再開一次，之後就唔會再有呢個問題。
7. **CSV 匯入淨係可以貼上**：而家可以喺匯入區直接揀一個 `.csv` 檔案，內容會自動讀入下面個格，唔使再喺手機逐隻字貼。題庫列表一次最多拎 500 題（之前係全部一次過拎，題庫大嗰陣會拖慢手機），頁面會顯示總題數，超過 500 會提示用篩選縮小範圍。
8. **管理員唔記得密碼就冇路走**：加咗 `scripts/reset-password.js`，喺伺服器本機跑就可以重設任何帳號嘅密碼（見下面「唔記得密碼」一節），唔使改資料庫。
9. **部署安全雜項**：加咗 `.gitignore`（`data/exam.db` 同上傳檔案唔會再唔小心入 Git）、HSTS 同 CSP 安全標頭。

未修、留待你決定嘅嘢：開放註冊（任何人都可以自行註冊，公開之前要決定係咪加邀請碼或者管理員批核）、模擬考冇限時（而家個計時器淨係顯示用時，唔會到時自動交卷）、刷題重複做同一題每次都計入正確率、登入鎖定存喺記憶體（伺服器重啟會清空）、上傳檔案淨係驗副檔名、孤兒上傳檔案冇清理工具、未收集考生聯絡資料。

**更新方法同之前一樣**：成個資料夾上傳覆蓋舊版，**唔好刪 `data/`**，今次**唔使 `npm install`**（冇新依賴），然後 `pm2 restart exam-system`。第一次啟動會自動幫舊資料庫加 `snapshot` 欄位，舊卷、舊模板、舊成績全部保留。

## 題目媒體（圖片／影片）

**⚠️ 今次更新之後，伺服器要先跑一次 `npm install`（多咗 `multer` 依賴），唔跑會起唔到；之後再 `pm2 restart exam-system`。**

題目可以加最多 5 個媒體，圖片或者影片：

- **放邊度**：圖片放題幹（跟住題目內容顯示）或者答案選項（選項 A／B／C／D 嗰格可以係純文字、純圖片，或者文字加圖片）；影片主要放解析（例如一條短片講點解答案係咁），解析除咗影片都可以有圖片。
- **邊度睇到**：題幹媒體喺刷題、模擬考作答、錯題本、題庫預覽、成績報告逐題檢視都會顯示；選項圖片顯示喺該選項隔籬；解析嘅影片同圖片只會喺解析顯示嗰陣先出現（刷題答完顯示解析、成績報告檢視嗰陣）。媒體唔包含答案，唔會影響計分。
- **三種加入方法**（題庫管理 → 新增／修改題目）：
  1. **上傳檔案**：用檔案選擇掣，可以一次揀多個；手機會彈出影相／揀相／拍片。檔案存喺伺服器 `data/uploads/`。
  2. **貼外部連結**：貼圖片或者影片嘅 http(s) 連結。
  3. **CSV 匯入**：`media` 欄，見下面一節。
  加嗰陣要揀放邊度（題幹、選項 A／B／C／D、解析）；選項字母數目會跟住選項行數即時變。
- **檔案限制**：圖片只接受 jpg / jpeg / png / gif / webp，唔多過 5 MB；影片只接受 mp4 / webm / mov，唔多過 20 MB。唔接受 svg、html、exe 等（防 XSS 同路徑穿越）。上傳只限管理員，考生撳會返 403。檔案名會用隨機名儲存，唔用你原本嘅檔名。
- **刪除題目唔會一併刪除上傳咗嘅檔案**：因為同一份檔案可能畀多條題目共用，刪題嗰陣淨係刪題目紀錄，`data/uploads/` 入面嘅檔案會留低，唔會誤刪其他題用緊嘅圖或者片。想清理孤兒檔案，要自己經 SFTP 入 `data/uploads/` 刪除。
- **備份**：成站備份 JSON 包題目嘅媒體連結（邊個位置都包），但係唔包上傳咗嘅檔案本身。備份媒體要另外經 SFTP 下載 `data/uploads/`，還原嗰陣一齊傳返上去；如果淨係還原 JSON 而冇傳返檔案，題目嗰啲本地上傳圖片／影片會顯示唔到，外部連結就唔受影響。

## 匯入 CSV

1. 登入管理員，去「題庫管理」。
2. 撳「下載 CSV 範本（含示例）」，或者撳「睇範本內容」再一鍵複製。
3. 範本欄位：`question_id,type,content,options,answer,explanation,exam,difficulty,media`。
4. **記得刪走範本入面嗰 4 行示例（DEMO-001 至 DEMO-004）先至匯入**，否則示例題都會入埋題庫。範本入面 DEMO-001 嘅 `media` 欄有個例子（`stem:https://example.com/eg-ship.jpg`），DEMO-003 有選項圖片例子（`optA:https://example.com/eg-yes.jpg`），DEMO-004 有解析影片例子（`explanation:https://example.com/eg-ch16.mp4`），呢啲只係格式例子，用你自己嘅連結代替。
5. `exam` 欄填 `VTS` 或者 `430`；`options` 用 `|` 分隔（例如 `左舷讓路|右舷讓路`），判斷題填兩個選項（例如 `正確|錯誤`）；`type` 只可以係單選、多選、判斷、簡答；`difficulty` 只可以係簡單、中等、困難。
6. `media` 欄可以留空；有多個連結用 `;` 分隔，前面加前綴指定位置：`stem:連結`（題幹，唔寫前綴都當題幹）、`optB:連結`（選項 B 嘅圖片）、`explanation:連結`（解析嘅影片或者圖片）。例子：`stem:https://…/船圖.jpg;optB:https://…/選項圖.png;explanation:https://…/解說.mp4`，程式按副檔名自動分圖片定影片（mp4 / webm / mov 係影片，其他係圖片）。唔啱格式嘅連結會跳過，並喺匯入報告講明邊行邊個連結，唔會令成行題目匯入失敗；超過每題 5 個上限嘅連結一樣跳過，匯入報告會講明。
6. 匯入有兩個方法：貼上 CSV 內容再撳匯入，或者用範本檔案對照格式。重複編號可以揀跳過或者覆蓋。
7. 匯入同時兼容舊 `chapter` / `章節` 欄位名，會當做 `exam` 處理。
8. 答案格式有驗證：單選只准一個字母，多選字母會自動排序，字母超出選項範圍或者判斷題答案唔係選項之一，會即刻報錯講明邊行邊題。

## 放上伺服器部署（VPS）

以下係大概步驟，適用於一般 Ubuntu VPS（已經裝好 Node.js 22+）：

1. 將成個資料夾上傳去伺服器，例如 `/opt/exam-system`。
2. 喺伺服器入面：
   ```bash
   cd /opt/exam-system
   npm install
   ```
3. 用 `pm2` 等佢長期跑住，唔使開住 terminal：
   ```bash
   npm install -g pm2
   pm2 start server.js --name exam-system
   pm2 save
   pm2 startup
   ```
   預設跑喺 port 3000，可以用環境變數改 port：`PORT=8080 pm2 start server.js --name exam-system`。
4. 用 `nginx` 做反向代理，等訪客用 `https://你嘅域名` 開到，唔使打 port：
   - nginx 監聽 443（HTTPS），轉發去 `http://127.0.0.1:3000`。
   - 用 `certbot` 攞免費 HTTPS 證書：`sudo certbot --nginx -d 你嘅域名`。
5. 防火牆只開 80、443，唔好直接對外開 3000。
6. 第一次上線後，先喺網上建立管理員帳號，再用 CSV 匯入 VTS / 430 題目。

## 備份同還原

### 方法一：喺網站入面備份（建議，平時用呢個）

登入管理員，去「儀表板」最底「備份與匯出」：

- **匯出題目 CSV**：成個題庫，格式同匯入範本一樣，可以直接用嚟備份題目，或者搬去另一部機再匯入。題庫管理頁仲可以匯出目前篩選結果。
- **匯出學生帳號 CSV**：帳號、角色、建立日期、答題數、正確率，唔包含密碼雜湊。
- **下載成站備份 JSON**：一個檔案包晒題目、帳號、考卷紀錄、答題紀錄、留言、收藏、登入狀態、模擬考草稿同組卷模板（v1.1.0 起包埋模板，之前版本漏咗）。題目嘅媒體連結（包括位置）都有包，但係上傳咗嘅圖片／影片檔案本身唔包在內，要另外經 SFTP 下載 `data/uploads/` 一齊備份（見上面「題目媒體」一節）。
- **還原備份 JSON**：揀返之前下載嘅備份檔再撳還原。用合併方式寫入：按題目編號、帳號、紀錄編號逐行新增或者更新，唔會清空現有資料；還原完會逐張表回報新增 / 更新 / 跳過幾多行；中途出錯會成個取消，唔會還原一半。還原前建議先下載一份最新備份。

⚠️ **成站備份 JSON 包含密碼雜湊，唔好公開分享、唔好放上網、唔好經唔加密嘅渠道傳送，妥善保存在自己部機或者加密儲存。** 學生帳號 CSV 唔含密碼雜湊，相對安全。

### 方法二：手動備份資料庫檔案

資料庫就係 `data/exam.db` 一個檔案，備份即係複製呢個檔案：

- 備份：用 WinSCP / SFTP 連入伺服器，將 `data/exam.db` 下載返自己部機，檔名可以加埋日期，例如 `exam-backup-2026-11-13.db`。複製之前最好喺冇人用緊嗰陣做，穩陣啲。或者喺伺服器入面：`cp data/exam.db exam-backup-YYYY-MM-DD.db`。
- 上傳咗嘅圖片／影片唔喺 `exam.db` 入面：佢哋喺 `data/uploads/`，備份嗰陣要一併下載呢個資料夾；還原嗰陣一併傳返上去，否則題目嗰啲本地上傳圖片／影片會顯示唔到。
- 還原：**一定要先停咗程式**（例如 `pm2 stop exam-system`），再將備份檔案覆蓋返去 `data/exam.db`，然後重新啟動（`pm2 start exam-system`）。**唔可以直接喺程式行緊嗰陣覆蓋資料庫檔案**，會整壞個資料庫。
- 搬去另一部機：將成個資料夾連埋 `data/exam.db` 一齊抄過去，嗰邊 `npm install` 之後 `npm start` 就得，帳號、題目、成績、留言全部跟住去。

## 模擬考組卷選項

去「模擬考」頁，上面嗰張「開新模擬考」卡可以咁樣組卷：

- **考試（可剔多個）**：剔 VTS、430 或者其他考試值，隨機抽題會由全部剔咗嘅考試入面抽；預設全選。考卷名稱唔填嗰陣，會用剔咗嘅考試名自動命名，例如剔咗 VTS 同 430 就叫「VTS、430 模擬卷」。
- **難度（可剔多個）**：簡單 / 中等 / 困難，預設全選；只剔「困難」就淨係出困難題。
- **題數**：1 至 100，預設 10。
- **題目來源（以開卷嗰個用戶自己嘅作答紀錄計，唔同學生嘅題池唔同）**：
  - 全部題目：題庫入面所有非簡答題。
  - 未做過：你未答過嘅題（自由刷題同模擬考嘅作答紀錄都計）。
  - 做過的：你答過嘅題。
  - 錯題：你答錯過嘅題，啱晒溫習弱點。
- **題池數即時顯示**：考試、難度、來源一改，即刻顯示「符合條件嘅題目有 N 題」，題數欄旁邊亦會顯示題池上限。
- **題數大過題池**：會用晒題池全部題，唔會靜靜出少咗，並彈提示講明「符合條件得 N 題，已用晒」。
- **題池係 0 題**：例如錯題池未有題，會出錯提示（「錯題池暫時係空，請先做多啲題」），唔會開一份空卷。
- 簡答題唔會入模擬考（自動計分計唔到）。

## 按考試組卷（即場組合）

去「模擬考」頁，下面嗰張「按考試組卷」卡，唔使儲存，即場揀完即出卷：

- 每行一個考試：勾選框、考試名、題庫現有題數（跟住上面揀緊嘅難度同題目來源即時計）、題數輸入（1 至 100 題）；考試列表淨係題庫真正有題嘅考試，匯入新考試嘅題之後會自動出現。
- 難度同題目來源用上面嗰組，共用、套用到每一個考試；下面實時顯示「合共 N 題（中文 3 題、英文 2 題、數學 4 題）」。
- 撳「出卷」就按每科數目隨機出題，唔同考試唔會重複題目；簡答題唔入模擬考。
- 某科題數大過題池（例如中文要 9 題但得 5 題），嗰科會用晒 5 題，開卷嗰陣會彈提示講明；成個組合加埋 0 題唔開卷；冇剔任何考試亦唔開卷。
- 同組卷模板嘅分別：呢度係即場組合，唔使儲存；模板係管理員預先儲存嘅固定配方，開卷嗰陣一撳即用。

## 組卷模板（固定出卷配方）

去「模擬考」頁，「用模板開卷」卡：

- 模板係管理員預先儲存嘅固定配方，例如「VTS 10 題、430 5 題」。下拉選單會顯示每個模板嘅規則摘要，未撳之前已經知會出咩卷，揀好撳「用模板開卷」就按模板數目隨機出題，唔同規則之間唔會重複題目。
- 模板係共用嘅：管理員建立之後，所有學生開卷都揀到；學生唔可以新增、修改、刪除模板。
- 管理員專用「組卷模板管理」區：填標題，加減規則行（每行：考試下拉——淨係題庫真正有題嘅考試；題數 1 至 100；難度勾選——全剔即全部難度；題目來源下拉），儲存之後即刻用到；列表每行顯示規則摘要、建立者、建立日期，有修改、刪除掣（刪除要確認）。
- 某條規則題池唔夠數，會用晒並彈提示講明；成個模板加埋 0 題唔會開卷。模板考試名如果之後冇題（例如相關題目刪晒），該規則出 0 題加有提示，其他規則照常。

## 學生表現分析（管理員）

登入管理員，去「儀表板」，「題庫總覽」下面嗰張「學生表現分析」卡。學生睇唔到呢張卡，亦調用唔到分析接口（會返 403）。

卡入面有四部分：

- **全站弱項**：按考試、按題型、按難度嘅正確率橫條，正確率低嘅排前面，正確率低過 60% 會變紅色，等你一眼睇到邊部分最弱。
- **必錯題目榜（頭 10 名）**：題號、題目內容、考試、題型、難度、答次、錯次、錯率。每行有「去題庫」掣，撳落去會跳去題庫管理頁並用該題號篩選，即刻睇到原題同解析。
- **學生一覽**：每位學生一列——帳號、答題數、正確率、完成模擬考份數、平均分、最近活躍、最弱考試。排序可以揀正確率由低至高（預設，等你搵到最需要跟進嘅學生）、答題數、最近活躍、完成模擬考份數。撳帳號名可以睇該學生詳情：各考試正確率、最近 5 份模擬考紀錄（卷名、分數、日期）、錯得最多嘅 5 題。
- **最近完成嘅模擬考**：最近 10 份已完成考卷，邊個學生、卷名、分數、交卷時間。

數字點計：

- 正確率 = 答對數 / 答題總數。簡答題喺刷題係學生自評對錯（模擬考組卷本身唔包簡答）；答題紀錄嘅對錯欄位係唔可以為空嘅整數，所以唔會有「未評分」紀錄拉低分母。
- 最弱考試：只計該學生答過 ≥3 題嘅考試，入面正確率最低嗰個；未夠 3 題就留空，唔好令人誤判。
- 學生答題少過 5 題嗰陣，正確率旁邊會標「樣本少」；完全未答過題嘅學生，正確率顯示「—」，最近活躍顯示帳號建立日期。
- 必錯榜排序先按錯率、再按錯次；只計有作答紀錄而且曾經答錯過嘅題。題目如果已經喺題庫刪除，唔會出現喺榜上面（因為題目內容已經唔知係乜）。
- 模擬考平均分 = 各份已完成考卷「得分 / 總題數」嘅平均值，用百分比顯示。

## 唔記得密碼

管理員唔記得密碼，唔使成個資料庫刪走重嚟。喺伺服器入面：

```bash
pm2 stop exam-system
node scripts/reset-password.js <帳號> <新密碼>
pm2 start exam-system
```

新密碼至少 6 個字。重設之後，該帳號舊嘅登入狀態會全部失效，要用新密碼重新登入。呢個指令只喺伺服器本機跑，唔經網絡，唔會暴露出街。

## 安全注意事項

- **HTTPS 要靠 nginx**：呢個程式本身只係 http，公開俾人用一定要經 nginx 加 certbot 攞 HTTPS 證書（部署嗰節第 4 步），否則登入密碼同 token 會以明文傳送。防火牆只開 80、443，唔好直接對外開 3000。
- **開放註冊**：而家任何人都可以自行註冊考生帳號，係原設計，方便學生自己開戶。如果之後想收緊（例如只限你批核先入得、或者用邀請碼），話我知再加。
- **備份檔敏感**：成站備份 JSON 包含密碼雜湊，唔好公開分享，妥善保存。
- **登入保護**：同一 IP 同同一帳號，15 分鐘內登入失敗 5 次會暫時鎖 15 分鐘，時間到自動解鎖，唔會鎖死管理員帳號；登入狀態 30 日過期，過期要重新登入；新密碼最少 6 個字，舊帳號唔受影響。
- **管理員帳號密碼要夠強**：管理員可以睇晒全部資料、匯出成站備份，密碼唔好用太簡單嘅組合，亦唔好同其他網站共用。

## 唔可以直接放上 GitHub Pages

GitHub Pages 只能夠放靜態網頁，冇後端、冇資料庫。呢個系統要有登入、題庫、答題紀錄、模擬考，全部要靠後端同 SQLite，所以唔可以直接放上 GitHub Pages。要公開俾人用，一定要放喺自己嘅 VPS 或者長期開住嘅電腦上面跑。

## 注意事項

- 伺服器每次重啟唔會登出所有人，因為登入狀態係存喺資料庫。
- 簡答題唔入模擬考自動計分，只喺刷題模式出參考答案自評。
- 首次啟動寫入嘅 Test-001 係試驗題，正式用之前可以用題庫管理刪走佢。
