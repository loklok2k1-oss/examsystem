# 考試系統 — 獨立版

呢個係可以下載、自己保存、上傳去自己伺服器嘅獨立版考試系統，VTS 同 430 備考用。唔係 Muse 入面先用得嘅版本，有前後端加資料庫。

## 入面有乜

- 帳號：首次開啟先建立管理員帳號，之後考生自行註冊；密碼用 PBKDF2 雜湊，唔存明文；分考生同管理員角色；帳號管理可以升降級；登入狀態存資料庫，伺服器重啟唔會登出晒所有人。
- 題庫管理（管理員）：單題新增、修改、刪除連選項編輯器、預覽連解析；按考試、難度、題型、關鍵字篩選；CSV 批次匯入，欄位缺漏逐行報邊行錯，重複編號可以揀跳過或者覆蓋；CSV 範本用 `exam` 欄位，含 4 行示例，匯入前要刪走示例行；另有睇範本內容加一鍵複製，同直接貼上 CSV 內容匯入；答案格式有驗證，唔會存入永遠答唔啱嘅題。批量管理：每題可以勾選，全選今頁 / 全選篩選結果 / 取消全選，批量刪除（連答題紀錄、收藏、相關留言一併清除）、批量改分類（VTS / 430）、批量改難度。
- 匯出備份（管理員）：儀表板「備份與匯出」可以匯出題目 CSV（格式同匯入範本一樣）、匯出學生帳號 CSV（唔含密碼雜湊）、下載成站備份 JSON、還原備份 JSON（合併方式，失敗成個取消）；題庫管理頁可以匯出目前篩選嘅題目 CSV；帳號管理頁可以匯出學生帳號 CSV。
- 安全：密碼 PBKDF2 雜湊（新註冊同改密碼最少 6 個字）、登入失敗 5 次鎖 15 分鐘、登入狀態 30 日過期、基本安全 headers、管理員接口全部要管理員身份、考生唔可以直接由題目列表拎到答案。
- 刷題模式：按考試、難度、題型隨機抽題，一題一頁，交答案即顯示對錯同解析，解析預設收起，可以收藏；簡答出參考答案自評。
- 模擬考：隨機組卷或者手動選題，計時器、題號導覽、標記待檢查、暫停離開後再登入可恢復，恢復時直接跳去第一條未答嘅題；交卷自動閱卷，多選順序唔敏感；成績報告逐題連解析；考卷列表可以刪除考卷；考試頁底部有固定狀態列，顯示計時、已答、未答、待檢查數同自動暫存時間；未交卷草稿唔會漏入錯題本。
- 錯題本：自動收集，按考試、來源批次篩選（自由刷題或者邊份模擬考卷），每題顯示來源，錯題重做模式。
- 留言：全域留言板加每題討論，管理員或者本人可以刪除。
- 儀表板：個人（答題總數、正確率、各考試正確率、模擬考分數趨勢）同管理員（題庫總數、題型分佈、難度分佈、各考試題目分佈，X 軸用整數刻度）。
- 其他：深色模式可切換；手機頂部導覽自動換行；彈窗可以用 Esc 關閉；登入狀態同主題用安全儲存，瀏覽器封鎖儲存都唔會全頁白屏；載入出錯會顯示原因同恢復掣。

## 檔案

- `server.js` — 後端（Express + SQLite），全部接口都在入面
- `package.json` — 只需要裝 `express`，資料庫用 Node 內置 `node:sqlite`
- `public/index.html`、`public/app.js` — 前端（原生 HTML / CSS / JS，唔使 build）
- `seed.json` — 種子資料，首次啟動寫入一條試驗題 Test-001（Math、單選、中等）
- `data/` — 資料庫檔案 `exam.db` 會喺首次啟動自動建立，唔使你手動整
- `README.md` — 呢份說明

## 安裝同啟動

需要 Node.js 22 或以上版本（建議 Node.js 24 LTS），去 https://nodejs.org 下載。

```bash
npm install
npm start
```

之後用瀏覽器開 http://localhost:3000 。

## 首次建立管理員

1. 第一次開啟，頁面會話你建立管理員帳號，填帳號同密碼（至少 6 個字），撳註冊。
2. 之後考生可以撳註冊自行開帳號，預設係考生角色。
3. 管理員可以喺「帳號管理」將考生升級做管理員，或者將管理員降級。

## 匯入 CSV

1. 登入管理員，去「題庫管理」。
2. 撳「下載 CSV 範本（含示例）」，或者撳「睇範本內容」再一鍵複製。
3. 範本欄位：`question_id,type,content,options,answer,explanation,exam,difficulty`。
4. **記得刪走範本入面嗰 4 行示例（DEMO-001 至 DEMO-004）先至匯入**，否則示例題都會入埋題庫。
5. `exam` 欄填 `VTS` 或者 `430`；`options` 用 `|` 分隔（例如 `左舷讓路|右舷讓路`），判斷題填兩個選項（例如 `正確|錯誤`）；`type` 只可以係單選、多選、判斷、簡答；`difficulty` 只可以係簡單、中等、困難。
6. 匯入有兩個方法：貼上 CSV 內容再撳匯入，或者用範本檔案對照格式。重複編號可以揀跳過或者覆蓋。
7. 匯入同時兼容舊 `chapter` / `章節` 欄位名，會當做 `exam` 處理。
8. 答案格式有驗證：單選只准一個字母，多選字母會自動排序，字母超出選項範圍或者判斷題答案唔係選項之一，會即刻報錯講明邊行邊題。

## 放上伺服器部署（VPS）

以下係大概步驟，適用於一般 Ubuntu VPS（已經裝好 Node.js 22+）：

1. 將成個資料夾上傳去伺服器，例如 `/opt/exam-system`。
2. 喺伺服器入面：
   ```bash
   cd /opt/exam-system
   npm install
   ```
3. 用 `pm2` 等佢長期跑住，唔使開住 terminal：
   ```bash
   npm install -g pm2
   pm2 start server.js --name exam-system
   pm2 save
   pm2 startup
   ```
   預設跑喺 port 3000，可以用環境變數改 port：`PORT=8080 pm2 start server.js --name exam-system`。
4. 用 `nginx` 做反向代理，等訪客用 `https://你嘅域名` 開到，唔使打 port：
   - nginx 監聽 443（HTTPS），轉發去 `http://127.0.0.1:3000`。
   - 用 `certbot` 攞免費 HTTPS 證書：`sudo certbot --nginx -d 你嘅域名`。
5. 防火牆只開 80、443，唔好直接對外開 3000。
6. 第一次上線後，先喺網上建立管理員帳號，再用 CSV 匯入 VTS / 430 題目。

## 備份同還原

### 方法一：喺網站入面備份（建議，平時用呢個）

登入管理員，去「儀表板」最底「備份與匯出」：

- **匯出題目 CSV**：成個題庫，格式同匯入範本一樣，可以直接用嚟備份題目，或者搬去另一部機再匯入。題庫管理頁仲可以匯出目前篩選結果。
- **匯出學生帳號 CSV**：帳號、角色、建立日期、答題數、正確率，唔包含密碼雜湊。
- **下載成站備份 JSON**：一個檔案包晒題目、帳號、考卷紀錄、答題紀錄、留言、收藏、登入狀態同模擬考草稿。
- **還原備份 JSON**：揀返之前下載嘅備份檔再撳還原。用合併方式寫入：按題目編號、帳號、紀錄編號逐行新增或者更新，唔會清空現有資料；還原完會逐張表回報新增 / 更新 / 跳過幾多行；中途出錯會成個取消，唔會還原一半。還原前建議先下載一份最新備份。

⚠️ **成站備份 JSON 包含密碼雜湊，唔好公開分享、唔好放上網、唔好經唔加密嘅渠道傳送，妥善保存在自己部機或者加密儲存。** 學生帳號 CSV 唔含密碼雜湊，相對安全。

### 方法二：手動備份資料庫檔案

資料庫就係 `data/exam.db` 一個檔案，備份即係複製呢個檔案：

- 備份：用 WinSCP / SFTP 連入伺服器，將 `data/exam.db` 下載返自己部機，檔名可以加埋日期，例如 `exam-backup-2026-11-13.db`。複製之前最好喺冇人用緊嗰陣做，穩陣啲。或者喺伺服器入面：`cp data/exam.db exam-backup-YYYY-MM-DD.db`。
- 還原：**一定要先停咗程式**（例如 `pm2 stop exam-system`），再將備份檔案覆蓋返去 `data/exam.db`，然後重新啟動（`pm2 start exam-system`）。**唔可以直接喺程式行緊嗰陣覆蓋資料庫檔案**，會整壞個資料庫。
- 搬去另一部機：將成個資料夾連埋 `data/exam.db` 一齊抄過去，嗰邊 `npm install` 之後 `npm start` 就得，帳號、題目、成績、留言全部跟住去。

## 安全注意事項

- **HTTPS 要靠 nginx**：呢個程式本身只係 http，公開俾人用一定要經 nginx 加 certbot 攞 HTTPS 證書（部署嗰節第 4 步），否則登入密碼同 token 會以明文傳送。防火牆只開 80、443，唔好直接對外開 3000。
- **開放註冊**：而家任何人都可以自行註冊考生帳號，係原設計，方便學生自己開戶。如果之後想收緊（例如只限你批核先入得、或者用邀請碼），話我知再加。
- **備份檔敏感**：成站備份 JSON 包含密碼雜湊，唔好公開分享，妥善保存。
- **登入保護**：同一 IP 同同一帳號，15 分鐘內登入失敗 5 次會暫時鎖 15 分鐘，時間到自動解鎖，唔會鎖死管理員帳號；登入狀態 30 日過期，過期要重新登入；新密碼最少 6 個字，舊帳號唔受影響。
- **管理員帳號密碼要夠強**：管理員可以睇晒全部資料、匯出成站備份，密碼唔好用太簡單嘅組合，亦唔好同其他網站共用。

## 唔可以直接放上 GitHub Pages

GitHub Pages 只能夠放靜態網頁，冇後端、冇資料庫。呢個系統要有登入、題庫、答題紀錄、模擬考，全部要靠後端同 SQLite，所以唔可以直接放上 GitHub Pages。要公開俾人用，一定要放喺自己嘅 VPS 或者長期開住嘅電腦上面跑。

## 注意事項

- 伺服器每次重啟唔會登出所有人，因為登入狀態係存喺資料庫。
- 簡答題唔入模擬考自動計分，只喺刷題模式出參考答案自評。
- 首次啟動寫入嘅 Test-001 係試驗題，正式用之前可以用題庫管理刪走佢。
